# Edusmart_AI
EduSmart AI Test Generator &amp; Evaluator: upload or paste study notes (.txt, .pdf, .docx, .pptx) and instantly get a 10, 25, 50 or 100-question practice test, Easy to Hard. Smart answer checking, scores, topic analytics and a personal study plan. Works offline; add a free Gemini API key for AI questions and grading. React, TypeScript, Vite, Tailwind.
